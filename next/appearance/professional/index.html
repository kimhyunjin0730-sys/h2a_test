Signature Presence Program

전문성을 Signature Presence로

PROGRAM INFO

대상기업 임원, 전문직, 차세대 리더, Entrepreneur, Consultant
기간3개월 (격주 1회 3시간)

다시 만나고 싶은 사람으로 완성되는 3개월

전문성이 있다고 해서 그 가치가 저절로 전달되는 것은 아닙니다. 자신의 성취와 전문성이 어떻게 보이고, 어떻게 행동으로 드러나며, 어떤 감정으로 기억되는지를 훈련합니다.

단순한 지식 전달이 아니라 자신의 실제 사례를 가지고 실습하고 피드백 받는 3개월 소수 정예 Private Group Coaching Program입니다.

프로그램 구성

  • Master Class 30%
  • Personal Case Clinic & Practice 40%
  • Personal Feedback 30%
보조 설명 · 화면 검수용 초안

이런 분께 권해 드립니다

  • 전문성과 실력에 비해 첫인상이나 소통 방식에서 한계를 느끼시는 전문가
  • 자신만의 고유한 브랜드를 구축하고 신뢰감을 주는 이미지를 완성하고자 하는 리더
  • 소수 정예 그룹 내에서 객관적인 피드백과 코칭을 통해 변화를 경험하고자 하는 분

CURRICULUM

  • SESSION 01 — READ ME

    나는 어떻게 읽히는가

    • 3A 사전 진단
    • 현재 습관 점검
    • 의도한 인상 vs 실제 인상
    • 60초 영상 진단
    • 목표 Presence 설정

  • SESSION 02 — APPEARANCE

    신뢰가 보이게 하라

    • 역할과 지위에 맞는 TPO
    • 옷보다 사람이 기억되는 스타일
    • Signature Style
    • 외적 표현 기준

  • SESSION 03 — ATTITUDE I

    몸이 먼저 말한다

    • 자세·시선·표정·제스처
    • 인사
    • 공간과 거리감
    • 비언어 습관 교정

  • SESSION 04 — ATTITUDE II

    품격은 화법에서 드러난다

    • 목소리 톤과 속도
    • 경청과 질문
    • 칭찬과 거절
    • 비즈니스 대화
    • 30초 자기소개

  • SESSION 05 — AFFECT

    어떤 감정을 남길 것인가

    • 편안함과 안정감을 주는 대화
    • 정서적 여운
    • 관계의 거리감
    • 다시 만나고 싶은 사람의 행동
    • Social Appeal

  • SESSION 06 — SIGNATURE PRESENCE

    나만의 3A를 완성하다

    • 비즈니스·사교 상황 Simulation
    • 사전/사후 영상 비교
    • Personal Feedback
    • Presence Code 완성
    • 90-Day Action Plan

과정을 통해 달라지는 것

  • 사전·사후 3A 변화 분석을 통해 교육 전후의 실질적인 태도와 커뮤니케이션 변화를 점검합니다.
  • 30초 자기소개와 Personal Presence Code를 완성하여, 짧은 순간에도 자신의 전문성을 명확하게 각인시킵니다.
  • Signature Style Code와 교정해야 할 습관 리스트를 바탕으로 90일간의 실천 계획을 수립합니다.
